# LLM 排行榜 - 快速开始

## 访问排行榜

启动开发服务器后，访问以下 URL：

```
http://localhost:3000/llm
```

或者在生产环境：

```
https://your-domain.com/llm
```

## 页面结构

### 1. 页面顶部
- **标题**: LLM 模型排行榜
- **副标题**: 基于使用量、性能和质量的综合排名
- **数据周期**: 显示数据的时间范围和最后更新时间
- **快速导航**: 4 个按钮快速跳转到各个板块

### 2. 总体排名表格
展示所有模型的综合排名，包含以下列：
- 排名（前3名高亮显示）
- 模型名称和分类
- 提供商
- 使用量（Token数，以B/M/K为单位）
- 请求数
- 平均延迟（毫秒）
- 质量评分（0-100）
- 趋势（↑上升 ↓下降 −稳定）

### 3. 使用趋势图
- 最近30天的使用量变化
- 显示Top 10模型
- 支持图例点击切换显示/隐藏
- 底部滑块可缩放时间范围
- 鼠标悬停显示详细数据

### 4. 市场份额饼图
- 按提供商统计的市场份额
- 显示百分比、Token总量、模型数量
- 鼠标悬停查看详情
- 点击图例切换显示/隐藏

### 5. 分类排名
三个分类卡片：
- **通用**: 通用对话模型
- **编程**: 代码生成和编程辅助
- **多模态**: 支持图像等多模态输入

每个分类显示Top 5模型及其使用量。

### 6. 说明板块
- 数据来源说明
- 排名指标解释
- 更新频率
- 趋势符号含义

### 指标说明

**使用量 (Tokens)**:
- 统计周期内处理的总Token数
- 单位：B（十亿）、M（百万）、K（千）

**请求数**:
- 统计周期内的API调用次数
- 反映模型的使用频率

**平均延迟**:
- 从请求到首个Token的平均时间
- 单位：毫秒（ms）
- 越低越好

**质量评分**:
- 综合评分（0-100）
- 考虑输出质量、准确性、有用性等

**趋势**:
- ↑ 排名上升（数字表示上升位次）
- ↓ 排名下降（数字表示下降位次）
- − 排名稳定（无变化）

## 常见问题

### Q: 数据多久更新一次？
A: 当前配置为每小时更新一次。可在 `app/api/llm/leaderboard/route.ts` 中修改 `revalidate` 值。

### Q: 如何添加新模型？
A: 编辑 `lib/llm/mock-data.ts` 中的 `MOCK_MODELS` 数组，添加新模型信息。

### Q: 如何接入真实数据？
A: 参考 `LLM_RANKINGS_README.md` 中的"数据源配置"章节。

### Q: 图表不显示怎么办？
A: 检查浏览器控制台是否有错误，确认 ECharts 正确安装。

### Q: 如何自定义样式？
A: 修改各组件中的 Tailwind CSS 类名和 ECharts 配置。
